# DemoTG

## Objetivo
Este proyecto está siendo realizado con el objetivo de ser presentado como un trabajo de grado enfocado en el desarrollo de una aplicación móvil con realidad aumentada como una herramienta de aprendizaje acerca de una especie de abeja conocida como Angelita y por su nombre científico (Tetragonisca Angustula).

## Infraestructura del proyecto
El proyecto está realizado principalmente en Unity para la creación de la aplicación móvil y la implementación de otros frameworks y utilidades como: Vuforia Engine, para la visualización de los modelos 3D dentro del aplicativo; Blender, para el modelado y animación de los modelos 3D; Firebase, para el almacenamiento de los usuarios y registros con el sistema de autenticación.
